# Recording

- `framing-guide-9x16.png`: 9:16 guide (eyes line, face oval, chest zone for graphics, platform UI red zones). Used by OBS scene "Framing check".
- `obs/`: backup of the OBS profile + scene collection "Video Pipeline" (copy into `%APPDATA%/obs-studio/basic/profiles/` and `.../scenes/`). The recording path points at a project's `RECORDINGS/` folder (`../<project>/RECORDINGS/...`); change it per project.
  OBS rewrites its config on exit: only edit these files with OBS closed.
- Phone link camera into OBS is 1280x720 only: framing checks yes, final recording no (record on the phone).
- A recording checklist (phone, mic, teleprompter) belongs in the project: `../<project>/RECORDINGS/HOW TO RECORD.md`.
