# Audio

- **Voice cleanup** is in the editor (`tools/editor/helpers/clean_audio.py`): RNNoise + 25% dry, then two-pass loudnorm to -14 LUFS.
- **SFX** `make_sfx.py <out.wav>`: pops, impacts, whooshes, risers synthesised with numpy, placed on exact times.
  Edit the time constants at the top (copied from 06; one per beat). Run with the editor env: `cd tools/editor && uv run python ../audio/make_sfx.py out.wav`.
- **Music** `music/`: licensed tracks. `club-no-copyright-618622.mp3` = "Club No Copyright" by MiroMaxMusic, Pixabay Content License (free, no attribution; may draw a YouTube Content ID claim). ~128 BPM, drops at 0:15.3 and 1:15.6.
  Retime to a grid with `rubberband=tempo=<target/source>`; land the drop on a visual hit.
- **Beat grid** `beats.py <track>` (run in the editor env) → JSON with bpm, beats, downbeats, hits, builds (build-ups: `ramp` or `pre-drop`, top 5). Beat phase comes from the kick band (fixed 2026-11-02: the grid ran ~0.14 s early before); a detected drop sets the downbeats. Club track: 127.6 BPM, drops on downbeats at 15.39 and 75.58 (beats 32 and 160), builds from ~4.1 and ~68.1. Tempo on clips under ~30 s can lock to a wrong multiple: measure the full track.
- **Splice to length** `splice_music.py <track> <grid.json> --segments "8-16,144-168" --length 15 --gap 24 --out bed.wav`: rebuilds a bed from beat ranges, cuts on the beat (12 ms pre-roll + crossfade), optional duck before the drop, fade-out. Example = 2 intro bars + the second build + 2 bars of drop, drop at 11.29 s. Output is 1.5 dB down (the club track clips at 0 dBFS).
- **Real SFX** `openverse_sfx.py search|get "whoosh" --max-sec 3 --n 5`: recorded sounds from Openverse (mostly Freesound), no key, CC0 by default → `sfx/openverse/<query>/` + `credits.json` (gitignored). Anonymous API = 20 results per query; slow and 504-prone on cold queries (it retries).
- **earshot** (`earshot/`, v0.4.0, MIT, CPU; https://github.com/Leonxlnx/earshot): lets the agent HEAR. `earshot rank "a short airy whoosh" sfx/openverse/whoosh/*` picks the best download; `timeline mix.wav [--video v.mp4]` = second-by-second listening transcript + sync of sounds to cuts; `critique film.mp4` = scorecard vs pro launch films; `describe`, `find`, `measure`; `sfx render ID` / `kit` = 252 code-made sounds aimed at a frame. Run: `GEMINI_API_KEY= GOOGLE_API_KEY= tools/audio/earshot/.venv/Scripts/earshot.exe <cmd>` (the blank keys keep its optional Gemini critique from ever billing). Each CLI call loads models for ~20-40 s; for many calls use one Python script (`from earshot import api`) or its MCP server (`.mcp.json` at the toolkit root: 16 tools, models stay warm, active in sessions started in this folder; keys blanked there too, so `llm_critique` never runs). Reinstall: clone, `uv venv --python 3.12 .venv`, CPU torch, `uv pip install -e ".[mcp]"`, `earshot doctor --fetch` (~2.1 GB with models).
- **Mixing recipes:** music-only motion video: bed 0.6 + SFX 0.8 → loudnorm -14. Voice + bed: bed ~12-15 dB under a TTS voice, ducking a few dB under speech.
- Measure every mix: `ffmpeg -i x -af ebur128=peak=true -f null -` (target -14 LUFS, true peak under -1).
